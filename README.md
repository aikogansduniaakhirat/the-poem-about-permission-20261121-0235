A short, fixed poem connects a mother's open door with a late-night request for permission, turning remembered care into responsibility. The dependency-free Node 22 program writes its exact UTF-8 text without a trailing newline and verifies the bytes on disk. No network access is used.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The poem is written to `out/entry.txt`. Without `MAKEFUN_OUTPUT_DIR`, the output directory defaults to `/output`.
